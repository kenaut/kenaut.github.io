# 我写了一个快捷开关机的软件

## 为什么会有这个项目

说实话，我平时用电脑最烦的就是关机、重启、锁屏这些操作。每次都要点开菜单，再点一下，太磨叽了。尤其是锁屏，我这种经常离开电脑的人，一天要锁好几次。

我就想，能不能按一个键，直接弹个小窗口，再按一个键就执行？于是 qrdock 就诞生了。

## 它是什么

qrdock 是一个跨平台的系统操作启动器。用全局热键呼出，然后快速执行关机、重启、注销、锁屏、挂起这些操作。

支持 Linux 和 Windows，内置 7 种语言，配置用 Lua 写。

## 技术栈

用 Python + PyQt6 写的。核心逻辑很简单：

- `system/` 里按操作系统区分动作模块，Linux 和 Windows 各一套
- `ui/` 里是启动器窗口和语言选择对话框
- 配置用 Lua 格式，存在用户配置目录

## 遇到的坑

最麻烦的是跨平台。Linux 和 Windows 的关机命令完全不一样，得分别处理。还有全局热键，每个桌面环境绑定方式都不一样，光文档就写了一大堆（GNOME、KDE、niri、Hyprland、Sway、i3……）。

## 现状

目前还在完善中，还没发布到 PyPI。不过打包这块已经做了不少：Arch 的 PKGBUILD、Fedora/RHEL 的 rpm spec、Debian/Ubuntu 的 deb、Windows 的安装脚本都有。

以后等稳定了再考虑发布，可能还会加点动作，或者支持更多平台。先这样吧。
