# 变形不再靠死记硬背：认识 BNMB，一款开源的日语动词活用训练工具

**让日语动词变形，从反复背诵变成有目标的练习。**

学习日语的过程中，动词活用一直是绕不开的一道关卡。

从最基础的ます形、ない形、て形，到可能形、意向形，再到受身形、使役形和使役受身形，不同动词分类对应着不同的变化规则。

仅仅依靠课本和笔记，很容易出现这样的情况：

- 看着规则好像明白了，真正做题却不会变形。
- 单独记住了某个动词，换一个动词就不知道如何处理。
- 学过的活用形容易遗忘，缺少持续性的练习。
- 缺乏有效的训练反馈，不清楚自己究竟薄弱在哪里。

为了解决这些问题，我们开发了 **BNMB（变にまび）**。

这是一款开源的日语动词活用训练工具，希望通过更加直观、系统的练习方式，让日语学习者逐步掌握动词变形。

---

## 一、BNMB 是什么？

BNMB（变にまび）是一款基于 Web 技术开发的日语动词活用训练工具。

它借鉴了多邻国式的练习思路，将日语动词变形拆分为不同的训练项目，通过填空、选择、训练回合和学习统计等功能，帮助学习者熟悉日语动词的变化规律。

它不需要注册账号，也不需要安装复杂的软件。

打开网页，就可以开始练习。

**在线体验：**

https://kenaut.github.io/BNMB/

---

## 二、12 种活用形，系统覆盖日语动词变形

BNMB 目前支持 12 种日语动词活用形：

| 分类 | 活用形 |
|---|---|
| 基础活用 | 辞书形、ます形、ない形、て形、た形 |
| 进阶活用 | 可能形、意向形、命令形、条件形（ば） |
| 被动与使役 | 受身形、使役形、使役受身形 |

同时，系统支持多种动词分类：

- 五段动词
- 一段动词
- サ变动词（する）
- カ变动词（来る）
- 特殊变化动词，例如行く、ある等

无论是基础阶段还是进阶阶段，都可以找到相应的训练内容。

## 三、不只是选择题：多种训练方式

为了避免单一练习方式带来的局限，BNMB 提供了两种主要题型。

**1. 填空训练**

根据题目给出的动词和目标活用形，输入正确答案。

支持汉字与假名作答，并兼容日语输入法。

**2. 四选一训练**

从四个选项中选择正确的动词形式。

干扰选项优先从同一个动词的其他活用形式中生成，让练习更加有针对性。

此外，BNMB 还支持正向与逆向两种出题方向：

- 正向：辞书形 → 目标活用形
- 逆向：目标活用形 → 还原辞书形

不仅要会变形，也要能够反向识别。

## 四、循序渐进的学习机制

BNMB 并不打算一开始就把所有复杂的活用形式全部开放。

系统采用分批解锁机制。

初始开放ます形、ない形、て形和た形四种基础活用。

当学习者逐步掌握当前批次的内容后，便可以解锁下一批训练：

- 第一阶段：基础活用
- 第二阶段：可能形、意向形、命令形、条件形
- 第三阶段：受身形、使役形、使役受身形

每种活用形都需要达到相应的掌握条件，才能继续推进。

让学习者从基础开始，一步一步挑战更复杂的内容。

## 五、597 个动词，覆盖 JLPT N5—N1

目前，BNMB 内置了 **597 个日语动词**，覆盖 JLPT N5 至 N1 的不同学习阶段。

词库包含：

- 日语汉字
- 假名读音
- 中文释义
- 动词分类
- JLPT 等级

同时，系统支持自动标注振假名，方便学习者阅读和辨认。

对于希望长期学习日语的人来说，这意味着可以在一个工具中持续积累动词活用经验。

## 六、训练结果，也是一种学习反馈

完成每轮训练后，BNMB 会生成对应的训练结果。

每回合包含 10 道题目，并提供：

- 实时答题进度
- 训练用时
- 正确题数
- 最终正确率
- 平均每题用时

除此之外，系统还有学习统计功能。

可以查看总体学习进度、不同活用形的正确率、薄弱动词排行以及最近的训练成绩。

还加入了连续学习天数统计，让每一次练习都能够留下记录。

通过这些数据，学习者可以更加清楚地了解自己的学习情况。

## 七、轻量化、免登录、开源

BNMB 的 Web 版本采用 React、TypeScript 和 Vite 构建，并部署在 GitHub Pages 上。

它有几个值得关注的特点：

**无需后端**

纯前端静态应用，不需要服务器提供实时计算服务。

**无需账号**

不需要注册或登录即可使用。

**本地保存**

学习进度保存在浏览器本地，支持 JSON 格式的存档导出与导入。

**开源项目**

项目采用 MIT License 开源，欢迎开发者查看代码、提出建议以及参与改进。

项目源码：

https://github.com/kenaut/BNMB
